# Icônes

37 icônes SVG de 24 × 24 px, trait de 2 px, extrémités arrondies, dessinées d’une seule encre : encre `#15211D` (`encre-900`). Recolorez-les dans le code avec le token voulu (`texte`, `action`, `sante`…). Le kit de la charte contient les mêmes fichiers en `currentColor` pour React Native. La section Iconographie donne le sens de chaque icône.
