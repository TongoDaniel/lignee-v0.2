# Logos

Fichiers SVG vectorisés (le logotype est converti en tracés : aucune police n’est nécessaire).

- `lignee-logo-horizontal-nuit.svg` : symbole or `#F2B84B`, logotype crème `#F3ECE0`. Sur fond Nuit uniquement.
- `lignee-logo-horizontal-jour.svg` : symbole vert `#1E5A48`, logotype encre `#15211D`. Sur fond clair.
- `lignee-logo-horizontal-noir.svg`, `lignee-logo-horizontal-blanc.svg` : une seule encre, noir `#000000` ou blanc `#FFFFFF` (impression une couleur, photo avec voile).
- `lignee-logo-vertical-nuit.svg`, `lignee-logo-vertical-jour.svg` : version verticale, mêmes encres.
- `lignee-symbole-or.svg`, `-vert.svg`, `-creme.svg`, `-encre.svg`, `-noir.svg`, `-blanc.svg` : symbole seul, épaisseur standard (48 px et plus). L’encre est dans le nom.
- `lignee-symbole-compact-or.svg`, `-vert.svg`, `-creme.svg`, `-encre.svg` : symbole seul, trait épais, sous 48 px.
- `lignee-logotype-creme.svg`, `lignee-logotype-encre.svg` : « Lignée » seul.
