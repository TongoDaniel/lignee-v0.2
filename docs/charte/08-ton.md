# Ton et écriture

Lignée parle comme un proche bien organisé : chaleureux, précis, jamais pressant. Il vouvoie tout le monde, de l’adolescent au grand-père.

## Principes

- **Vouvoyer, toujours.** « Ajoutez vos parents », jamais « Ajoute tes parents ».
- **Dire ce qui se passe, avec des mots simples.** « Lignée lit le texte, même manuscrit, et affiche ce qu’elle a trouvé. »
- **Un bouton commence par un verbe**, à l’infinitif : « Ajouter », « Inviter », « Enregistrer ». Une question appelle une réponse en forme de bouton : « Oui, ajouter ».
- **Être exact sur les liens de parenté.** « Cousin issu de germain », « grand-tante », « demi-sœur », « beau-père ». Quand le lien est incertain, le dire : « Peut-être son frère ».
- **Ne jamais alarmer.** Une donnée de santé se dit sans adjectif ni pronostic.
- **Respecter le deuil.** Une personne décédée garde son prénom et ses années ; on n’écrit pas « défunt ».

## Vocabulaire

| Dites | Évitez |
| --- | --- |
| Fiche (d’une personne) | Profil, compte, nœud |
| Proches, famille | Contacts, utilisateurs |
| Lien de parenté | Relation, connexion |
| Antécédent de santé | Maladie, pathologie |
| Visible par vous seul | Privé (seul), confidentiel |
| Responsable de branche | Administrateur, modérateur |
| Proposition | Demande de modification, ticket |
| Capsule temporelle | Message programmé |
| Importer un arbre (fichier GEDCOM) | GEDCOM seul, sans explication |

## Situations

| Situation | Exemple |
| --- | --- |
| Écran vide | « Votre arbre commence par vous. Ajoutez vos parents en touchant les cercles. » |
| Confirmation | « Lucienne a rejoint l’arbre. » · « Antécédent enregistré, en privé. » |
| Notification | « Tante Awa a ajouté 12 personnes. » · « Odette fête ses 90 ans aujourd’hui. » |
| Erreur | « Ce fichier n’est pas un arbre GEDCOM. Exportez votre arbre au format .ged, puis réessayez. » |
| Santé | « Hypertension : 3 proches du côté paternel. C’est une information à évoquer avec votre médecin, pas un diagnostic. » |
| Confidentialité | « Vos antécédents de santé restent visibles par vous seul. » |
| Demande d’accord | « Activer le calque santé ? Ces données restent privées, visibles par vous seul. » Boutons : « J’accepte » / « Plus tard ». |
| Proposition | « Moussa Diallo · Profession : pêcheur → marin. Proposé par Nora. » Boutons : « Accepter » / « Refuser ». |

## À éviter

- Le tutoiement, l’argot, l’humour sur la mort ou la maladie.
- Les emoji, les points d’exclamation en série, les majuscules pour crier.
- Les phrases au passif (« Votre fiche a été mise à jour par le système ») : dites qui fait quoi.
- Les termes techniques de généalogie sans explication (« sosa », « ascendance agnatique »).
- Le point médian dans l’interface : préférez une formulation qui inclut tout le monde (« vos proches », « la personne »).
