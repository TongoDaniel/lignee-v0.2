# Carte

Le bloc de contenu de l’app : fond `fond-carte`, `rayon-carte`, `ombre-carte`, marge intérieure `espace-5`.

## Ce que vous fournissez

- Le contenu : titre (`titre-carte`), texte secondaire (`secondaire`), et au besoin une vignette de 52 px à gauche.
- `onPress` si toute la carte s’ouvre.

## Règles

- Les cartes se posent sur `fond`, séparées de `espace-4`. Pas de carte dans une carte.
- La vignette prend la teinte douce du type de contenu : `fete-douce` pour un album, `memoire-douce` pour un récit, `documents-douce` pour un acte.
- Pas de bordure colorée sur un côté, pas de dégradé.
