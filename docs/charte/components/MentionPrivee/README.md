# MentionPrivee

Dit qui peut voir une information, à côté de cette information.

## Ce que vous fournissez

- `cercle` : `vous`, `famille` (avec le nom de l’arbre), `responsables`, ou une liste de personnes.
- `sante` : variante en `sante-texte` pour les données de santé.

## Règles

- Icône `prive` (ou `famille` pour un cercle familial) de 16 px et texte `etiquette` en `texte-secondaire`.
- Elle accompagne toute donnée sensible : santé, coordonnées, date de naissance d’une personne vivante.
- Le texte est toujours explicite : « Visible par vous seul », jamais « Privé ».
