# OngletsFiche

Les trois rubriques de la fiche d’une personne : Souvenirs, Documents, Santé.

## Ce que vous fournissez

- `actif` : l’onglet affiché, `onChange`.

## Règles

- Libellés en Instrument Sans 16 ; l’onglet actif passe en graisse 600, `texte`, avec un trait de 4 px en `action` sous le mot. Les autres sont en `texte-secondaire`.
- L’onglet Santé n’affiche son contenu qu’à la personne qui l’a renseigné, ou après accord.
- Le changement d’onglet fait glisser le trait en 240 ms.
