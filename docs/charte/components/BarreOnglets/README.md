# BarreOnglets

La navigation principale de l’app, en bas de l’écran : Arbre, Famille, Santé, Mémoire.

## Ce que vous fournissez

- `actif` : l’onglet courant ; la navigation se charge du reste.

## Règles

- Quatre onglets, toujours dans cet ordre. Le profil s’ouvre depuis la photo en haut de l’écran, pas depuis la barre.
- Icônes de 28 px (`icone-l`) et libellés `legende`. Actif : `action` et graisse 600. Inactif : `texte-secondaire`.
- L’onglet Arbre utilise le symbole Lignée compact.
- La barre est posée sur `fond-carte`, avec un `filet` en haut, et respecte la zone de l’indicateur d’accueil du téléphone.
