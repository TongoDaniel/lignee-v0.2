# Logo

Les versions du logo sur leurs fonds autorisés : horizontal, vertical, symbole, logotype.

## Règles

- Sur Nuit : symbole or, logotype crème. Sur fond clair : symbole vert, logotype encre.
- Sous 48 px, le symbole compact. Zone de protection : la moitié du rayon de l’anneau.
- Les fichiers sont dans le groupe Logos ; la section Logo du guide détaille construction et interdits.
