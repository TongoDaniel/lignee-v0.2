# Icones

Le jeu d’icônes Lignée : 37 icônes au trait de 2 px sur une grille de 24 px, extrémités arrondies.

## Règles

- Couleur `texte` par défaut, `action` quand l’icône est active, couleur fonctionnelle quand elle porte un sens.
- Fichiers SVG dans le groupe Icônes (encre #15211D) ; versions `currentColor` dans le kit pour l’app.
- La section Iconographie du guide donne la liste et le sens de chaque icône.
