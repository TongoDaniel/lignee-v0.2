# Notification

La bannière d’une notification de l’app, telle qu’elle apparaît sur le téléphone ou en haut de l’app.

## Ce que vous fournissez

- `titre` : la personne d’abord, l’action ensuite. `texte` : une phrase qui invite à ouvrir.

## Règles

- Icône d’app (symbole or sur `vert-700`), surtitre « LIGNÉE », titre en Instrument Sans 17 graisse 700, texte `secondaire`.
- Jamais de donnée de santé ni de date de naissance complète dans une notification.
- Une notification par événement ; les ajouts en série se regroupent (« 12 personnes »).
