# EnTete

Le haut de chaque écran : titre, sous-titre facultatif, une action à droite.

## Ce que vous fournissez

- `titre` (`titre-ecran`, 30 px, graisse 700), `sousTitre` (`secondaire`, en `texte-secondaire`).
- `action` (facultatif) : un Bouton compact, ou la photo du profil.
- `retour` : affiche l’icône `retour` à gauche pour les écrans de détail.

## Règles

- Le titre dit où l’on est, en un ou deux mots : « Mon arbre », « Famille », « Fiche santé familiale ».
- Une seule action dans l’en-tête. Les autres vont dans le menu `plus`.
